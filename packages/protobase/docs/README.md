# Protobase documentation

This directory expands the top-level README with deeper guides, API notes, and
examples. If you are new to Protobase, start with the README and then jump to
the sections below.

## Index

- `core.md` - class system, slots, initialization, default values
- `immutability.md` - `Inmutable`, type checks, and frozen behavior
- `consed.md` - hash-consing and canonicalization
- `flux.md` - dependency-tracked queries and invalidation
- `api.md` - compact API reference
- `examples.md` - runnable examples and how to execute them
- `faq.md` - common questions and gotchas
